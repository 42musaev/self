ФОРМА — установка на iPhone (бесплатно)

1. Распакуйте ZIP на компьютере. В папке должны лежать index.html, manifest.webmanifest, sw.js и три PNG-иконки.
2. Создайте публичный репозиторий на github.com и загрузите все файлы из папки В КОРЕНЬ репозитория.
3. В репозитории откройте Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Дождитесь публикации. GitHub покажет HTTPS-ссылку вида https://USERNAME.github.io/REPOSITORY/.
5. Откройте эту ссылку в Safari на iPhone → Поделиться → На экран «Домой» → Добавить.
6. Один раз откройте установленную ФОРМУ с интернетом, чтобы сохранить файлы для работы офлайн. Затем записи сохраняются автоматически на этом iPhone.

ВАЖНО:
- Открытие index.html напрямую из «Файлов» не обеспечивает надежного сохранения и офлайн-режима PWA.
- Данные хранятся локально на устройстве, не в GitHub. Публикация репозитория НЕ публикует ваши записи.
- Не удаляйте веб-приложение и не очищайте данные сайтов без резервной копии. Регулярно нажимайте «Скачать резервную копию JSON» в разделе «Настройки и резервные копии», сохраняйте в «Файлы»/iCloud Drive.
- Данные Safari и установленного веб-приложения могут храниться отдельно: начните вести записи именно в иконке на главном экране.
- При смене iPhone импортируйте JSON в приложении через «Восстановить из JSON».
